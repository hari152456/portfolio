Hari Govind K Portfolio source code

Files:
- index.html: website structure and content
- styles.css: design and responsive layout
- script.js: current-year footer script
- assets/: screenshots and gameplay video

To run: keep the folder structure unchanged and open index.html in a browser.
To publish: upload the entire folder to a static host such as Netlify or GitHub Pages.

Icons: Lucide Icons are loaded from the Lucide CDN in index.html. An internet connection is required for the icon library to load.
